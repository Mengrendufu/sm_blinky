2. 借用式缓冲契约




create 只做两件事:把 config 里的值(尺寸、模式)
写进对象,再把 text
指针绑给 label——不复制字符串;
外观(font/color)随后由组件挂共享样式获得。
所以 config 用复合字面量即可,调用结束后配置结构
即可离开作用域——助手不保留它;
而缓冲与字体对象必须活得比 label 久。

5. 事实与示意口径




事实
助手只创建一个普通、去样式的 lv_label 子对象;
校验参数(含 textAlign 为合法四值)后按
longMode→size→textAlign→(仅非 NULL 时
flag/align)→static text 的顺序配置;
外观由组件在 create 之后挂 const 样式获得;
ignoreLayout=NULL 时完全不写控件位置/控件对齐;
非 NULL 时 x/y 相对父级内容区左上
(边框与内边距以内);不创建屏幕;config 不保留,
text 借用须长寿;DOTS 被契约拒绝,
其余字段原样转发 LVGL。


示意
第 1 节预览与第 3 节坐标是浏览器/SVG 教学推演:
字体替代、断行按浏览器规则,不加载固件字体、
不复刻 Figma、不是 MCU 实测,字宽舍入可能与
LVGL 不同;未编入字形的字符不保证可显示。
