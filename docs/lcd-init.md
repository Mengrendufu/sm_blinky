# LCD 初始化：双色 X 型可写性验证

`BSP_lcdInit()` 在调度器启动前执行，背光保持关闭。
初始化将采样验证通过作为面板可用的准入事实；它不是逐像素测试。
历史六列信标和清黑回读流程不再作为当前实现约定。
历史冷启动曾测到约 383 ms 状态位已就绪、但约 7.9 s 才能可靠写入；
这是继续保留实际写入验证的依据，不是新版耗时测量。

## 顺序

1. 初始化 GPIO、FSMC BANK4 和 DMA，补足复位后 5 ms 命令间隔。
2. 发送一次软复位，等待至少 5 ms，再周期读取 ID。
3. 只有读到本板预期 ID `0x8552`，才进入退出休眠阶段。
4. 补足软复位到 SLPOUT 的 120 ms 间隔；通信探测时间计入其中。
5. 发送 SLPOUT，等待 5 ms 后开始配置寄存器、检查状态和双色 X 验证。
6. 验证失败延时后再试，成功则置 `verified=1` 并全屏清黑，不再回读。
7. 发送 DISPON、记录面板 ID，返回时背光仍关闭。

普通命令的 5 ms 最小间隔与复位后 SLPOUT 的 120 ms 限制仍保留。
SLPOUT 后的 120 ms 限制针对 SLPIN，不再解释为禁止访问 GRAM。
通信成功只表示芯片可达，不能代替写入验证。

寄存器表在信标之前配置，验证通过后不再重配。
UI HSM 后续在 Splash entry 开背光并请求绘制。

## 采样与判定

每一行采样两条对角线的位置，共 640 点：

```text
x0 = y * (width - 1) / (height - 1)
x1 = width - 1 - x0
```

当前 240×320 尺寸下，同一行两点不同，覆盖四角和全部行。
颜色按行、对角线和轮次交替使用品红 `0xF81F`、绿色 `0x07E0`。
这两个 RGB565 颜色互补，且不受 R/B 对调影响。

每轮先写完采样点，再逐点读取并与该位置的预期颜色精确比较。
第二轮交换颜色，使同一位置必须接受变化，拒绝旧图恰好匹配、
整片固定读值以及被测位置拒写等情况。首个读值不再充当校准基准。
两轮通过共需 1280 次点写和 1280 次像素读；耗时需板端测量。
未采样位置或某些地址别名故障仍可能漏检，不作完整显存测试承诺。

## 回读格式

正常写入仍为 RGB565。每轮读取前切换 COLMOD 为 `0x66`，
RAMRD 丢弃 dummy 后读取两个 16 位字，按 RGB666 的 R/G、B
打包格式归一化到 RGB565。无论通过还是失败，都恢复 COLMOD `0x05`。
双色只使用通道极值，精确比较不依赖原先的单色容差。

依据：[ST7789V 数据手册][st7789]
§8.8.11（16-bit MDT=00 打包）、§9.1.23（RAMRD、COLMOD）。
本板已通过生产初始化的回读验证；覆盖范围和启动耗时见下方记录。
宿主模型不能代替其他模组、低温或供电条件下的目标板验证。

## 重试和诊断

ID 探测最多 1100 次，失败间隔 10 ms，不重复发送软复位。
通信超时直接返回，保留最后读到的 ID，`verified=0`，不发送 SLPOUT、
不配置画面、不清屏、不发送 DISPON。

通信通过后，可用性检查另有最多 1100 轮的预算；状态检查失败等待
10 ms，信标失败等待 20 ms。此阶段保留现有预算耗尽行为：
仍发送 DISPON 并返回，`verified=0`。调用返回不能代替验证结果。

记录 103/104/105/106/108 报告耗时、可用性尝试次数、状态检查失败、
双色可写性验证失败、验证结果；109 单独报告 ID 通信失败次数。
107（清黑回读失败）退休，不复用。外部 `blinky_hmi.json` 同步配对。

## 历史板端测量：固定延时版本（2026-10-28）

同板、J-Link 连接、每版三次调试器请求复位，按目标 HAL tick 计时：
旧版 LCD 初始化均为 409 ms，新版均为 400 ms，减少 9 ms（约 2.2%）。
两版均首轮通过，新版 `verified=1`、状态及可写性失败计数均为零。
BSP 整体阶段同样从 409 ms 降为 400 ms；这不是首帧或冷上电时长。

首次上板暴露状态检查依赖先配置寄存器表；已恢复每轮先配置、再检查，
并将此顺序加入宿主测试。最终验证通过后仍不再重写寄存器表。
证据：`/tmp/lcd-x-board/report.md`。此组数据属于固定延时版本，
不代表当前周期探测版本。
