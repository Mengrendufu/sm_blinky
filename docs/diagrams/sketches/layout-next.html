四、要你定的三件事

  1. 页 2 已定：按你说的「随便放点组件 + 动效」= 上图 live 页（spinner + switch + 12 根 cpu 历史条 + led ✓，合计 ≈3% 占用）。
  2. 今天 blinky 的那套东西去哪：节拍环（七步/边沿）、edges/frame 卡、底栏帧时条 —— 新方案里没有它们的位置。选一个：(a) 搬到页 1 清单下面（要压掉 2 根条）； (b) 搬到页 2 换掉历史条；(c) 就删掉（板子上从此只看资源，不看 blinky 自己的节拍）。
  3. 栈要列哪几行：全部任务一行一行（最多 5~6 行）还是按占用取前 N + 其余合计？
  4. “sm 事件池”指哪个：SST 静态事件池（字面 ✓，需加一个 free 读数）还是 UI inbox（现成 ✓）？
