估算公式：脏区 px × (1.2 µs 渲染 + 0.16 µs 刷屏)，两个系数来自 charter §6 的实测（方块 72×72 = 5,184 px → 渲染 ≈6 ms；每行字 72×24 = 1,728 px → ≈2.2 ms；flush 1.35 ms / 8,640 px）。
结论：弧 ≤ 96×96（≈9,200 px）可以连续动画；132×132 的弧（17,424 px）只能做一次性过渡；整屏动画（76,800 px ≈104 ms）在这颗片子上不可能 —— 上限约 9.6 fps。
多控件同时动画要算总和：弧 + 进度条 = 11,712 px ≈ 16 ms ≈ 48% ✓ 可行；再叠两个方块就到 76% ✗ 太紧。
