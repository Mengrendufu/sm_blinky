① 右上角：cpu NN % + led —— 两页都在（页 1 的弧里也有一份，角落那个不取消 ✓）。
② cpu 用半圆 lv_arc：bbox 156x78 ⇒ 整行带 3 条 ≈ 10 ms/次，2 Hz ⇒ 占用 ~2%。
③ 清单每行 = 条 + 百分比 + 数字（mockup 原话）。线程全放：运行期就 5 个任务 —— ui(2048 w) / flash(256 w) / ao(SST，所有 AO 共用一个入口，任务名就是 "ao"，见 ports/sst_port.c:61) / Tmr Svc(256 w) / IDLE(128 w) —— 再加 tracer nmin + SST 事件池 + UI inbox = 8 行✓ （面板 164 px ÷ 8 行 = 20 px/行，还余 4 px；最多能到 8~9 行 ⇒ 以后加任务也放得下 ✓）。
④ 页点保留（两页指示）。
⑤⑥⑦⑧ 页 2「随便动起来」：dial 弧（连续转，36x36 区域，≈0.9 ms/帧 ⇒ 30 fps ≈ 2%）+ switch（跟 ledOn 同步翻转，每次 ≈2 ms、2 Hz ⇒ 0.4%）+ 12 根 cpu 历史条（每 500 ms 插一根，用现成的 lv_bar，每窗 ≈1.5 ms ⇒ 0.3%）+ led 闪烁。合计 ≈3%，不碰大动画。
    代价：需要开 LV_USE_SPINNER 与 LV_USE_SWITCH（bsp/lvgl/lv_conf.h 现在是 0 ⇒ +约 3 KB flash）； LV_USE_CHART 建议不开（+6 KB 且走画线路径，历史条已经够用）。
